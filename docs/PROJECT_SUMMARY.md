# 刷怪监控助手 - 项目总结

## 项目概述

**功能**：实时监控游戏聊天框，识别刷怪地点，预测下一轮刷新位置，发出抢妖提醒。

**技术栈**：Python + PyQt5 + RapidOCR + mss

**核心逻辑**：
- 游戏刷怪按4组循环刷新，每组有固定地点池
- 识别当前刷新地点 → 计算下一组 → 预测可能刷新的地点

---

## 地点分组数据

```
第1组：蓬莱仙岛、碗子山 (各50%概率)
第2组：麒麟山、北俱芦洲、朱紫国 (各33.33%概率)
第3组：大唐国境、江南野外、建邺城、蓬莱仙岛、碗子山、波月洞 (各16.67%概率)
第4组：傲来国、大唐境外、长寿郊外、波月洞 (各25%概率)
```

---

## 遇到的问题与解决方案

### 1. OCR识别率问题

**问题**：游戏聊天框文字是黄色，OCR识别率很低。

**解决**：
- 截图后放大2倍（提高清晰度）
- 将黄色像素转换为白色（提高对比度）
- 使用RapidOCR引擎（比Tesseract识别率更高）

```python
# 黄色文字转白色
yellow_mask = (
    (pixels[:,:,0] > 180) &
    (pixels[:,:,1] > 140) &
    (pixels[:,:,2] < 150)
)
pixels[yellow_mask] = [255, 255, 255]
```

---

### 2. OCR误识别问题

**问题**：地点名称经常被识别错误：
- "碗子山" → 硼子山、烷子山、婉子山
- "蓬莱仙岛" → 蓬菜仙岛、篷莱仙岛、逢莱仙岛
- "大唐国境" → 大I害国、害国i竟

**解决**：采用**2字组合匹配**，而非完整字符串匹配：

```python
LOCATION_KEYWORDS = {
    "蓬莱仙岛": ["仙岛", "蓬莱", "蓬仙", "莱仙"],  # 只要匹配任意一个
    "碗子山": ["子山", "碗子", "碗山"],
    "大唐国境": ["国境", "大唐"],
    ...
}
```

**优势**：即使部分字符识别错误，只要能识别出关键2字组合就能命中。

---

### 3. 框选区域包含干扰元素

**问题**：用户框选区域太大，包含聊天框按钮、箭头等，OCR识别出英文乱码。

**解决**：过滤非中文字符，只保留中文：

```python
import re
text = re.sub(r'[^一-鿿]', '', text)  # 只保留中文字符
```

---

### 4. 多条消息同时显示

**问题**：框选区域可能同时显示多条聊天消息，旧消息干扰识别。

**解决**：只取最下面那条文字（Y坐标最大的）：

```python
# OCR返回多个文字块，按Y坐标排序
all_texts.sort(key=lambda x: x[0], reverse=True)
bottom_text = all_texts[0][1]  # 取最下面的
```

---

### 5. 相同地点跨轮次被跳过

**问题**：碗子山在第1组和第3组都有，如果连续两轮都刷碗子山，会被错误跳过。

**解决**：添加时间判断，超过15秒认为是新的一轮：

```python
if detected_location == self.last_detected_location:
    if (current_time - self.last_detected_time) < 15:
        return  # 15秒内重复检测，跳过
    # 超过15秒，认为是新的一轮，继续处理
```

---

### 6. 提醒逻辑优先级问题

**问题**：用户监控"碗子山"，当前组刷了"蓬莱仙岛"，下一组可能有碗子山。但"miss提醒"覆盖了"prepare提醒"。

**解决**：重新设计优先级：
```
1. warning（红色）- 当前刷到监控地点，最高优先级
2. prepare（黄色）- 下一组可能有监控地点
3. miss（灰色）- 当前组有监控地点但没刷到
4. normal（默认）- 正常状态
```

---

### 7. 提醒自动消失问题

**问题**：用户希望提醒常驻显示，不要几秒后自动消失。

**解决**：
- 移除alert_timer定时器
- 提醒区域持续显示当前状态
- 根据状态持续闪烁变色

---

### 8. GUI布局优化

**问题**：日志区域太小，窗口不好拖动调整。

**解决**：
- 合并设置、监控地点、控制按钮到顶部一行
- 状态信息合并到一行
- 跑马灯标签更紧凑
- 日志区域使用stretch=1占据剩余空间
- 默认窗口尺寸800x600

| warning | 红色 #ff0000 | 抢妖警告！监控地点刷新了 |
