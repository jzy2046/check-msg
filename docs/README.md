# 刷怪监控助手

实时监控游戏聊天框，预测刷新地点，自动发出抢妖提醒。

## 功能特点

- 🔍 **手动框选区域** - 精确选择聊天框位置
- 🎯 **智能预测** - 根据分组规律预测下一轮刷新
- ⚠️ **多重提醒** - 红色背景闪烁 + 声音警告
- 📝 **实时日志** - 记录所有检测事件

## 分组规律

刷新按组循环：第1组→第2组→第3组→第4组→第1组...

每组内地点出现概率均等：

| 组别 | 地点 | 每个地点概率 |
|------|------|-------------|
| 第1组 | 蓬莱仙岛、碗子山 | 50% |
| 第2组 | 麒麟山、北俱芦洲、朱紫国 | 33.33% |
| 第3组 | 大唐国境、江南野外、建邺城、蓬莱仙岛、碗子山、波月洞 | 16.67% |
| 第4组 | 傲来国、大唐境外、长寿郊外、波月洞 | 25% |

**注意：** 蓬莱仙岛、碗子山在第1组和第3组都有，波月洞在第3组和第4组都有。

## 安装步骤

### 1. 安装Python
确保已安装 Python 3.8 或更高版本

### 2. 安装依赖
```bash
pip install -r requirements.txt
```

### 3. 安装Tesseract OCR（重要）
OCR识别需要Tesseract引擎：

**Windows:**
1. 下载安装包: https://github.com/UB-Mannheim/tesseract/wiki
2. 安装时勾选 "Additional language data" -> "Chinese - Simplified"
3. 添加安装路径到系统环境变量 PATH（通常是 `C:\Program Files\Tesseract-OCR`）

### 4. 运行程序
双击 `run.bat` 或运行：
```bash
python monster_monitor.py
```

## 使用方法

1. **选择区域** - 点击"框选聊天框"，用鼠标拖拽选择聊天框区域
2. **添加监控地点** - 在输入框输入要监控的地点名称（如"碗子山"），点击添加
3. **开始监控** - 点击"开始监控"按钮
4. **接收提醒**:
   - 当下一组包含监控地点时 → 红色提醒"准备抢妖"
   - 当监控地点真正刷新时 → 红色闪烁+声音"抢妖警告"
5. 提醒会在5-8秒后自动消失，继续监控

## 提醒逻辑

```
当前刷新碗子山(第1组)
    ↓
预测下一组是第2组(麒麟山/北俱芦洲/朱紫国)
    ↓
如果用户监控"麒麟山"
    ↓
聊天框检测到刷新 → 红色提醒"准备抢妖"
    ↓
真正刷新"麒麟山" → 红色闪烁+声音警告"抢妖！"
```

## 注意事项

1. 聊天框文字需要是黄色高亮才能更好识别
2. 首次使用需要安装Tesseract中文语言包
3. 如果OCR识别不准确，可以调整聊天框区域选择范围
4. 程序每0.5秒检测一次，避免CPU占用过高

## 常见问题

**Q: OCR识别不到文字？**
A: 确保Tesseract已安装中文语言包，检查聊天框区域选择是否准确

**Q: 程序启动报错？**
A: 检查是否安装了所有依赖：`pip install -r requirements.txt`

**Q: 没有声音提醒？**
A: Windows系统使用系统蜂鸣音，确保系统音量已开启
